## Lab 03 — SONiC Containerlab Basics

| Lab | Status | Focus |
|---|---|---|
| Lab 03 — SONiC Containerlab Basics | Planned / In progress | SONiC boot, interface mapping, basic L3 connectivity, operational command discovery |

Lab 03 introduces SONiC as a cloud-networking-oriented NOS after the FRR-based underlay and EVPN/VXLAN labs. The first stage intentionally keeps the topology small so the lab can validate image availability, Containerlab behavior, interface mapping, and basic SONiC operations before moving into BGP or EVPN.
